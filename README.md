# ParrotFlow's Homebrew tap

```sh
brew install znat/tap/parrotflow
```

[ParrotFlow](https://github.com/znat/parrotflow) is programmable dictation for
macOS.

The cask in `Casks/` is written by `scripts/bump-cask.sh` in the app's own
repository and pushed here on every release. Send changes there, not here.
